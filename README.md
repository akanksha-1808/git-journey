# 🧠 DeciSense

AI-Powered Decision Intelligence Engine

## 🚀 Overview

DeciSense is a hybrid AI system designed to assist users in making structured, explainable decisions using:

- Rule-based reasoning
- Machine learning prediction
- Scenario simulation
- Confidence scoring
- Historical benchmarking

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly

## ✨ Features

- Decision ranking
- Risk analysis
- Scenario simulation
- ML-powered predictions
- Interactive analytics dashboard

## ▶ Run Locally

```bash
python -m streamlit run app/app.py
```
